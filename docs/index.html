這次公開的範圍

34 組研究候選、相關資產定位、來源封存檔 SHA-256、結構欄位觀察、支持與反對證據、查詢配方。這是完整本機博物館的公開研究子集。

完整掃描含 553,470 個唯一資產與 92,327 個已解析資源變體；原始遊戲 5,151 個檔案的前後 SHA-256 一致。25 項本機自動驗收通過，從保存 JSON 重建的資料庫已比對穩定欄位與全文。以上為參考掃描結果，不是其他安裝的保證。

判斷不等於定案

  • 29 組測試／開發殘留、1 組疑似刪除、4 組證據不足。
  • 沒有任何內容被宣稱為「確認遊戲內未使用」。
  • 動態載入、腳本與 TweakDB 的引用尚未完整納入。
  • 社群未匹配不等於全新發現；檔名不能單獨作為判斷。

獨立回歸樣本

MQ009 場景群、無名 UI Widget、無名 UI 動畫庫：三個資源目標屬於兩個內容家族。發現演算法不讀測試 fixture。另以 Q000、MQ008、EP1 MQ301 作正式流程反例。

TCRF 存取遭遇 403，未讀到的內容沒有當成已驗證證據。

穩定識別與延伸

研究群使用 NCA 識別碼；資產用 NCA-ASSET 加上路徑 hash。引用時一併記錄遊戲版本、scan ID 與封存檔 SHA-256。
